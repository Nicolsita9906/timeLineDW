Nace la World Wide Web

Tim Berners-Lee creó la World Wide Web en 1991. Esta tecnología permitió la creación de páginas web y la interconexión de información a través de Internet. La Web se basa en el protocolo HTTP (Hypertext Transfer Protocol) y el lenguaje HTML (Hypertext Markup Language), lo que facilitó el acceso a información multimedia desde cualquier lugar del mundo.
